# **TiTor**
## Time To Recharge

### Why this project
This is an app made to help you to handle yours lipos and yours batteries.
With TiTor you can easly managed the recharging time and choose the best moment to recharge yours lipos.

This app is based on sciences and my experience in drone FPV and everything is made to increase the timelife of yours lipos and their efficiency. 

I choose to build this app because I've spoil so many lipos because I didn't charge it at the best moment.
